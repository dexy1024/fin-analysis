# 申万二级 · 行业轮动流水线设计说明

> **维护约定**：调整 `shenwan_v2_trend_sectors.py` / `shenwan_v2_sector_leaders.py` 的阈值或分层逻辑时，**同步更新本文档**「可调参数」与「变更记录」两节。  
> 每日入口：`./run_shenwan_v2_daily.sh`

---

## 1. 核心哲学

**淘汰制，不是打分制。** 每一层只回答一个问题，不混用。

| 问题 | 层级 | 典型输出 |
|------|------|----------|
| 市场主线方向在哪？ | 第一层 · 战略 | `趋势标记=1`（含延伸段，**仅供对照**） |
| 资金轮动里，今天谁能接？ | 第一层 · 战术 | `可做标记=1`（**今日参与行业**） |
| 该行业里哪几只票能回踩接？ | 第二层 · 个股 | 写入 `observation.json` |
| 60m 有没有买点？ | 第三层 · 缠论 | 前端 60m 面板人工确认 |

**关键矛盾（已固化）：**

- **趋势最强 ≠ 今天能进。** 元件、半导体等延伸段行业是「风向标」，不是「新开仓目标」。
- **资金在轮动。** 从电子延伸段 → 化工/设备/低位板块，「可做」清单专门扫 **20 日未暴涨 + 拥挤未极致 + 资金边际流入** 的行业。

## 2. 流水线总览

```
run_shenwan_v2_daily.sh
  ├─ [1] shenwan_v2_sector_analysis.py      → 01_shenwan_v2_analysis_result.csv
  ├─ [2] shenwan_v2_volume_price_signals.py → 03_shenwan_v2_volume_price_signals.csv
  ├─ [3] shenwan_v2_crowding_monitor.py     → 05_shenwan_v2_crowding_monitor.csv
  ├─ [4] shenwan_v2_trend_sectors.py        → 06_shenwan_v2_trend_sectors.csv
  │                                         → 07_shenwan_v2_actionable_sectors.csv  ★
  └─ [5] shenwan_v2_sector_leaders.py       → 08_shenwan_v2_sector_leaders.csv
                                            → backend/data/observation.json（仅「可接」时）
```

### 2.1 三表输入（步骤 1–3）

| 表 | 回答什么 |
|----|----------|
| `analysis_result` | 行业相对沪深300：20 日涨幅、超额、均线多头、综合满足 |
| `volume_price_signals` | 价格趋势 + 120 日新高 + 成交额暴增 → **量价三重** |
| `crowding_monitor` | 成交额占全市场比例、120 日分位、3 日占比变化、分位斜率、连 3 日放量 |

### 2.2 第一层输出（步骤 4）

**文件 A：`06_shenwan_v2_trend_sectors.csv`** — 趋势分层 + 双标记

| 字段 | 含义 |
|------|------|
| `趋势层级` | 核心 / 复活 / 主线 / 量价 / 早期 / 观察 |
| `趋势标记` | **1 = 当前最强趋势方向**（核心优先，含延伸段） |
| `可做标记` | **1 = 与 actionable 表同步的今日首选** |
| `参与模式` | `延伸观察` / `可做` / `轮动试探` |
| `持筹信号` | 持有 / 抱团稳固 / 警惕撤离 / 建议出局 / 复活观察 / 观察 |
| `出局阈值` | 文字规则，供持仓对照 |

**文件 B：`07_shenwan_v2_actionable_sectors.csv`** — 全市场「能做」扫描（★ 日常主要看这个）

- 数据源：`analysis` 全量 × `crowding`（**不依赖** trend 表是否收录该行业）
- `可做得分 > 0` 且 `参与模式 ∈ {可做, 轮动试探}` 中 **Top N**（默认 **3**）→ `可做标记=1`
- 命令行可调：`shenwan_v2_trend_sectors.py --max-actionable 2`
- 延伸段行业也会列出，但得分为 **-1**，便于对照

### 2.3 第二层输出（步骤 5）

- **遍历** `actionable_sectors` 中全部 `可做标记=1` 的行业（fallback：`trend_sectors`；默认可多个，见 `MAX_ACTIONABLE_SECTORS`）
- 行业 gate 不通过 → `战术模式=观望`，**不写入** observation
- gate 通过 → 在成分股里筛「回踩 MA20 可接」龙头，最多 3 只

## 3. 第一层详细逻辑

实现文件：`backend/scripts/shenwan_v2_trend_sectors.py`

### 3.1 硬门槛：容量

- `成交额占比_pct ≥ MIN_CAPACITY_SHARE_PCT`（默认 **1.0%**）
- 低于门槛的小板块（非金属材料、玻璃玻纤等）**一票否决**，除非拥挤度状态为「异动」

### 3.2 趋势分层（`_classify_tier`）

优先级大致为：

1. **核心**：analysis 满足 + 量价三重 + 拥挤（或超级主线）
2. **复活**：主线 + 超级容量（≥3%）+ 拥挤 + 缺量价 + 日线回踩 MA20 缩量
3. **主线**：analysis 满足 + 拥挤
4. **量价**：analysis 满足 + 120 日新高放量，拥挤未标「拥挤」
5. **早期**：拥挤度「异动」
6. **观察**：analysis 满足 + 分位 ≥ 70% 但未标拥挤

### 3.3 持筹信号（拥挤边际）

当 `占比120日分位数 ≥ 95%` 时，看 **3 日边际**：

| 条件 | 信号 |
|------|------|
| 占比 3 日变化 ≤ -2.0 pct | 建议出局 |
| 占比 3 日变化 ≤ -0.5 pct 或分位斜率 < -0.5 | 警惕撤离 |
| 占比未衰减 | 抱团稳固 |
| 分位 < 95% | 持有 |

### 3.4 参与模式（延伸 vs 可做 vs 轮动）

函数：`_classify_participation`

| 模式 | 判定（任一组合） |
|------|------------------|
| **延伸观察** | 20 日涨幅 > 28%；或分位 ≥ 98%；或持筹 ∈ {警惕撤离, 建议出局}；或不满足可做/轮动 |
| **可做** | 在 analysis 榜内 + 容量够 + 20d ≤ 28% + 分位 < 95%；或层级为观察/量价 + 容量够 |
| **轮动试探** | 拥挤「异动」+ 容量够 + 占比/分位斜率抬升；或分位在 35–88% 甜蜜区 + 占比Δ>0 + 斜率>0 |

### 3.5 趋势标记 vs 可做标记

| 标记 | 函数 | 排序规则 | 用途 |
|------|------|----------|------|
| `趋势标记` | `_pick_trend_mark` | 核心 → 复活 → 主线；量价三重、连 3 日放量、占比Δ、20d 涨幅 | **看方向**，延伸段也标 1 |
| `可做标记` | `_build_actionable_universe` + `_actionable_score` | 可做得分最高 | **看今天做啥** |

### 3.6 可做得分（`_actionable_score`）

仅对 `参与模式 ∈ {可做, 轮动试探}` 计分，延伸段固定 **-1**。

| 因子 | 加分逻辑 |
|------|----------|
| 20 日涨幅 | 5–22% 甜蜜区 +35；否则按距 14% 衰减 |
| 分位 < 95% | +20 |
| 分位 35–88% | +15 |
| 占比 3 日变化 > 0 | 最多 +18 |
| 分位 3 日斜率 > 0 | 最多 +12 |
| 连 3 日放量 | +6 |
| 成交额占比 ≥ 3% / ≥ 1% | +12 / +6 |
| 模式=可做 | +8 |
| 持筹=警惕/出局 | -25 |

## 4. 第二层详细逻辑

实现文件：`backend/scripts/shenwan_v2_sector_leaders.py`

### 4.1 行业 Gate（安全阀）

即使已是「可做」行业，仍二次校验：

| 条件 | 结果 |
|------|------|
| 持筹 ∈ {警惕撤离, 建议出局} | 观望，不写 observation |
| 行业 20 日 > 28% | 观望 |
| 分位 ≥ 98% | 观望 |
| 全部通过 | `战术模式=可接` |

### 4.2 个股筛选（gate 通过时）

1. 成分股按**当日成交额**取 Top **10**
2. **距 MA20** 必须在 **[-3%, +8%]**（回踩区，不追暴涨）
3. 个股 20 日涨幅：`(行业 + STOCK_LAG_MIN)` ~ `(行业 + STOCK_EXCESS_MAX)`，默认超额 **-15 ~ +8 pct**
4. 排序：**越靠近 MA20 + 流动性越好**；取 **1–3** 只
5. 写入 `observation.json`；脚本托管的上轮标的会自动轮换清理

### 4.3 典型排除案例

- 东材科技、上纬新材：距 MA20 过远（已暴涨）
- 斯迪克：超额动量仍偏热（> +8 pct）
- 元件行业整体：20d +32%、分位 100% → 第一层即「延伸观察」，第二层不碰

## 6. 日常怎么用

```bash
./run_shenwan_v2_daily.sh              # 行业 + 龙头 + 端到端清单（有快照时）
./generate_snapshots.sh --write        # 观察池缠论快照（须显式 --write）
./pick_buyable_e2e.sh                  # 仅重算端到端表时可单独跑
```

**端到端一张表**：`09_shenwan_v2_buyable_e2e.csv`（脚本 `pick_buyable_e2e.py`）

**标的池（并集）**：`watchlist.json` 持仓 + `observation.json` 观察池 + 申万「可做行业」下 `sector_leaders` 扫描成分 / 入选龙头。

| 层级 | 含义 |
|------|------|
| `A_可买入` | 池内标的 + 快照 `实际交易动作=买入` + `日线风控=安全` |
| `B_盯盘` | 池内标的，缠论买点未齐或缺快照 |
| `X_排除` | 池内标的但日线破位、客观信号含卖等 |

`来源` 列：`持仓` / `观察池` / `申万龙头` / `申万扫描`（可多选，用 `+` 连接）。

硬规则：**现价 < min(日线A-ZD, 日线C-ZD) → 不买**（快照列 `日线风控=日线破位`）。

| 步骤 | 看什么 | 决策 |
|------|--------|------|
| 0 | `09_shenwan_v2_buyable_e2e.csv` → `A_可买入` | **唯一自动「可下单」候选** |
| 1 | 同表 `B_盯盘` | 等 15m 底背驰 + 区间对齐 |
| 2 | `06_shenwan_v2_trend_sectors.csv` → `趋势标记=1` | 知道主线在哪（元件等），**不追** |
| 3 | `07_shenwan_v2_actionable_sectors.csv` → `可做标记=1`（默认 **3** 个） | **今天主攻行业** |
| 4 | `08_shenwan_v2_sector_leaders.csv` → `入选龙头=1` | 回踩可接个股（日线） |
| 5 | 60m 面板 | 与快照交叉验证 |

## 7. 可调参数速查

### 7.1 `shenwan_v2_trend_sectors.py`

| 常量 | 默认 | 说明 |
|------|------|------|
| `MIN_CAPACITY_SHARE_PCT` | 1.0 | 容量硬门槛 % |
| `SUPER_MAIN_SHARE_PCT` | 3.0 | B 组复活超级主线 |
| `CROWDING_PCT_HIGH` | 95.0 | 拥挤边际起点 |
| `SHARE_DELTA_EXIT` | -2.0 | 占比 3 日撤离阈值 |
| `SHARE_DELTA_WARN` | -0.5 | 占比 3 日警惕阈值 |
| `ACTIONABLE_RET20_MAX` | 28.0 | 超过 → 延伸观察 |
| `ACTIONABLE_PCT120_MAX` | 95.0 | 超过 → 不可做（延伸） |
| `ACTIONABLE_RET20_SWEET_LO/HI` | 5 / 22 | 可做得分甜蜜区 |
| `ACTIONABLE_PCT120_SWEET_LO/HI` | 35 / 88 | 可做得分甜蜜区 |
| `MAX_ACTIONABLE_SECTORS` | 3 | 今日 `可做标记=1` 行业个数上限 |

### 7.2 `shenwan_v2_sector_leaders.py`

| 常量 | 默认 | 说明 |
|------|------|------|
| `SECTOR_RET20_MAX` | 28.0 | 行业 gate |
| `SECTOR_PCT120_MAX` | 98.0 | 行业 gate |
| `MA20_PULLBACK_MIN/MAX` | -3 / +8 | 回踩区 % |
| `STOCK_EXCESS_MAX` | 8.0 | 个股超额上限 pct |
| `STOCK_LAG_MIN` | -15.0 | 个股超额下限 pct |
| `TOP_LIQUID` | 10 | 流动性池大小 |
| `MAX_LEADERS` | 3 | 最多写入 observation 数量 |

## 9. 后续优化方向（备忘）

优化时优先对照本节，改代码后更新上文参数表。

- [ ] **轮动权重**：占比Δ、分位斜率在可做得分里的系数是否过敏感
- [ ] **可做 vs 轮动试探**：是否允许「轮动试探」也写 observation（当前仅「可做」优先标 1）
- [ ] **第二层容量**：塑料仅 1.1% 占比，是否对「可做」行业也设 SUPER 容量加分
- [ ] **个股池**：Top10 是否扩到 Top15；MA20 回踩区是否随波动率动态调整
- [x] **多行业并行**：默认可做 Top3（`MAX_ACTIONABLE_SECTORS`）；第二层对每个可做行业分别扫龙头并写入 observation
- [ ] **与 watchlist 联动**：手动 watchlist 与脚本托管 observation 的优先级
- [ ] **历史回测**：`logs/0[24]_shenwan_v2_*_history.csv` 上验证「可做」标记的次日/5 日胜率
